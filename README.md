# Evrone Post

Конструктор постов для Instagram Evrone. Открываете страницу в браузере, вставляете текст и картинку и скачиваете готовый пост 1080×1440 в PNG. Figma и дизайнер не нужны.

**Открыть конструктор: https://den-is-bezrukov.github.io/composter/**

Ничего устанавливать не нужно. Картинки никуда не загружаются, всё работает прямо в браузере.

## Что умеет

**Статья.** Анонс статьи из блога: крупный заголовок на чёрном фоне и 3D-иллюстрация.
- Заголовок сверху, снизу или «сэндвичем» (часть сверху, часть снизу). Шрифт и размер, как в макетах, подбирать не нужно.
- Картинку можно положить под текст или поверх него, двигать мышью и менять размер колёсиком.
- Если красный на иллюстрации вышел слишком ярким или жёлтым, его можно подправить. Нажмите на превью, чтобы сравнить с оригиналом.
- В помощи (кнопка «?») есть готовый промпт для ChatGPT: он рисует иллюстрации в стиле Evrone.

**Кейс.** Готовая картинка из проекта клиента и, если нужно, его логотип.
- Картинка всегда закрывает весь пост, пустых краёв не бывает. Кадр выбирается мышью и колёсиком.
- Логотип можно оставить своего цвета или перекрасить в белый или чёрный.

Конструктор сам предупредит, если заголовок не влезает или картинка слишком мелкая и получится мыльной.

## Как сделать пост со статьёй

1. Придумайте, что нарисовать: метафору темы статьи.
2. Нажмите «Скопировать промпт стиля», вставьте его в ChatGPT и допишите, что нарисовать.
3. Перетащите полученную картинку в конструктор и впишите заголовок.
4. Нажмите «Скачать».

Подробнее и с правилами хорошего поста написано в помощи, в самом конструкторе.

## Для разработчика

Страница собирается в один HTML-файл: шрифты и картинки-примеры встроены внутрь. Один и тот же файл работает на GitHub Pages и как артефакт на claude.ai.

```
src/page.html        разметка
src/style.css        стили
src/js/              скрипт по частям, склеивается в порядке из build.py
src/prompt.txt       промпт для иллюстраций
assets/              картинки-примеры
fonts/               Roboto Flex: ширина 60 и ширины 25–59 для ползунка «Ширина букв»
tools/make_fonts.py  пересобирает шрифты из вариативного Roboto Flex
build.py             собирает index.html и dist/artifact.html
```

Правки вносятся в `src/`, потом страница пересобирается:

```bash
python3 build.py
```

Сайт на GitHub Pages собирается из `index.html` в ветке `main`. Стабильные версии помечаются метками `vX.Y`.

### Шрифт

Заголовок набран Roboto Flex с настройками из макетов Figma: кегль 180, интерлиньяж 100%, трекинг +1%, капс, цвет `#EEEEEE`, поля 30 px. Canvas не умеет менять оси вариативного шрифта, поэтому каждая ширина сохранена отдельным файлом. Пересобрать шрифты:

```bash
pip install fonttools brotli
python3 tools/make_fonts.py "RobotoFlex[GRAD,XOPQ,XTRA,YOPQ,YTAS,YTDE,YTFI,YTLC,YTUC,opsz,slnt,wdth,wght].ttf"
python3 build.py
```

<details>
<summary>Значения осей</summary>

| ось | значение |
|---|---|
| wght | 800 |
| wdth | 60 (или 25–59 в «Настроить») |
| opsz | 144 |
| GRAD / slnt | 0 / 0 |
| XOPQ / YOPQ / XTRA | 96 / 60 / 468 |
| YTUC / YTLC / YTAS / YTDE / YTFI | 712 / 514 / 750 / −203 / 738 |

</details>

Roboto Flex распространяется по лицензии SIL Open Font License 1.1 (`fonts/OFL.txt`).
