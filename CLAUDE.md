# Evrone Article Posts

Конструктор постов-статей для Instagram Evrone, опубликован как артефакт:
https://claude.ai/artifact/VPVrM77jsDNwbu7d2LZzGV

Этот репозиторий — единственный источник правды для артефакта.

## Как вносить правки

1. Править `src/page.html` (разметка, стили, скрипт и промпт в одном файле).
2. `python3 build.py` — собирает `index.html` (GitHub Pages) и `dist/artifact.html`.
3. Опубликовать `dist/artifact.html` в артефакт, передав `url` выше, чтобы ссылка не поменялась.
4. Закоммитить изменения.

Не править артефакт в обход репозитория. Шрифты в `fonts/` генерируются через `tools/make_fonts.py`, руками их не трогать.

## Figma

Внешний вид — в Figma-файле [Evrone Post Builder](https://www.figma.com/design/b98SroxNlvHXWPNKJLfUZ6) (key `b98SroxNlvHXWPNKJLfUZ6`). На слово «синхронизируй» — процесс из `docs/figma-sync.md`: прочитать Figma скриптом `tools/figma-read.js`, сравнить с `design/figma-baseline.json`, показать список изменений, перенести в код, собрать, опубликовать, обновить снимок, закоммитить. Меняя внешний вид по текстовой просьбе, обновлять и Figma.

## Контекст

- Раскладка редактора: сайдбар 380 px с контролами слева, превью по центру справа (вписывается по высоте, `fitFrame()`), инструкция + промпт + правила — в модалке `#help`. Мобильная версия не нужна. Figma-экраны ещё под старую раскладку — обновить, если новая «зайдёт».
- Цвет иллюстрации (только «Статья»): четыре ползунка как в песочнице — оттенок, насыщенность, яркость красных и «Убрать желтизну» (тёплый налёт); по умолчанию нейтральные. Рецепт «нежнее»: +5°, 85%, 122%, 70%. Маски размыты на max(w,h)/500 px. Подбиралось в песочнице https://claude.ai/artifact/SdVFkAhSw14NAjPdReBC2t.
- Сохранение: «Скачать PNG» открывает окно `#save` только с именем файла (латиница, транслит, `.png` не редактируется, своё имя у каждого режима). Никаких строк статуса; ошибки показываются только внутри окна.
- Два режима: «Статья» (`state`, `drawArticle()`) и «Кейс» (`caseState`, `drawCase()`); `draw()` выбирает по `mode`. Кейс — только картинка + опциональный логотип клиента, без текста; один пост, без карусели.

- Макеты: Figma Evrone-SMM, фрейм «Evrone Instagram» (node 3575:6), файл `RCKCHPqo8R3qLuHxXJqjY04e`.
- Пользователь — маркетолог без Figma: интерфейс и тексты на русском, простые формулировки.
- Промпт иллюстрации: первые три блока на русском (НАРИСУЙ, ЗАДАЧА, ФОРМАТ), STYLE/COLORS/AVOID на английском. Формат — квадрат 1:1, PNG с прозрачным фоном.
- Заголовок: всегда кегль 180, «Авто» = wdth 60, «Узкая» = ползунок 25–60. Текст переносится сам по ширине блока, поддерживается неразрывный пробел.
- На GitHub репозиторий не выложен. Перед любым `git push` спрашивать подтверждение.
