# Evrone Article Posts

Конструктор постов-статей для Instagram Evrone. Две версии:
- **рабочая** — артефакт https://claude.ai/artifact/VPVrM77jsDNwbu7d2LZzGV, обновляется после каждой правки;
- **стабильная** — GitHub Pages https://den-is-bezrukov.github.io/evrone-article-posts/ (репозиторий https://github.com/den-is-bezrukov/evrone-article-posts, публичный), обновляется только по команде пользователя.

Этот репозиторий — единственный источник правды для обеих версий.

## Как вносить правки

1. Править `src/page.html` (разметка, стили, скрипт и промпт в одном файле).
2. `python3 build.py` — собирает `index.html` (GitHub Pages) и `dist/artifact.html`.
3. Опубликовать `dist/artifact.html` в артефакт, передав `url` выше, чтобы ссылка не поменялась.
4. Закоммитить изменения (локально, без пуша).

Не править артефакт в обход репозитория. Шрифты в `fonts/` генерируются через `tools/make_fonts.py`, руками их не трогать.

## Стабильная версия

`git push` только когда пользователь явно попросил выкатить стабильную версию (или просто «запушить»); без этого — никогда. Порядок: убедиться, что всё закоммичено и собрано, `git push origin main`, поставить метку следующей версии (`git tag vX.Y`, `git push origin vX.Y`), дождаться сборки Pages и проверить страницу. Откат — пересобрать с нужной метки.

## Контекст

- Дизайн редактора: Figma `1MKP3Xnm6sTpOf7ShQojJF` (Post-Builder), экран статьи — node 1:6502, экран кейса — 7:4348, кнопка помощи — 5:3610, шаблон кейса — 3:3531. Стиль панелей Figma UI3: Inter 11/16, сайдбары по 240 px, секции `.sec` с заголовком 40 px (`.sec-h`), строки `.row` / `.prop`, контролы 32 px; «Сбросить» (`.ghost`) в заголовке секции и бледнеет, когда сбрасывать нечего (`syncResets()`). Иконки раскладок и слоёв (квадрат — картинка) — точные пути из секции Icons в Figma (node 8:287) в `<symbol>`.
- Раскладка: слева шапка «Evrone Post / Instagram · 1080×1440» (стрелки меню нет, позже там будет выбор компании: он поменяет стиль и шрифт шаблона), «Шаблон» (только табы «Статья / Кейс»), «Текст» (иконки раскладки «Сверху / Сэндвич / Снизу», поле, неразрывный пробел), «Шрифт», внизу закреплён «Экспорт». По центру только превью (`fitFrame()`). Справа `#props`: в статье `#articleProps` — «Изображение» (иконки слоя, карточка, «Скопировать промпт стиля», «Масштаб», «Горизонтальное смещение», «Вертикальное смещение»; «Сбросить» в заголовке откатывает только масштаб и смещения), «Коррекция цвета»; Кейс — тоже три колонки, чтобы превью не прыгало при смене шаблона; правило: слева то, что поверх картинки (текст или логотип), справа картинка. Справа `#caseBg` — «Фон» (карточка картинки, «Масштаб», «Горизонтальное смещение», «Вертикальное смещение», «Сбросить» в заголовке); слева под «Шаблоном» `#caseProps` — «Логотип» (пустая карточка с «+»; после загрузки — карточка с корзиной «Убрать логотип», цвет «Как есть / Белый / Чёрный», «Масштаб» и смещения, «Сбросить» в заголовке; по фрейму Figma «Logo Added», node 22:6309). Все переключатели — `.seg`. В окне ≤960 px две колонки: `placeProps()` переносит `#props` под текстовые секции левой колонки, табов нет. Мобильная версия не нужна.
- Помощь: плавающая кнопка «?» справа внизу (`#helpBtn`) открывает `<dialog id="help">` (`openHelp()`); закрывается крестиком, Esc и кликом по фону.
- Кейс всегда без пустых краёв: картинка закрывает весь пост (`clampCase()`), масштаб только крупнее, X/Y двигают её в пределах того, насколько она выходит за край (диапазон ползунков пересчитывается в `drawCase()`, если выходить некуда — ползунок выключен). Перетаскивание мышью и масштаб колесом на превью работают. «Вписать целиком», «Без пустых краёв» и фон под краями убраны: такой результат нельзя публиковать.
- Превью в обоих шаблонах: картинку можно тянуть мышью, колёсиком или щипком менять размер вокруг курсора, ползунки едут следом (`panBy()` / `zoomBy()`, пределы — диапазоны ползунков). В «Статье» нажатие на превью сразу показывает оригинал без цветокоррекции, начало перетаскивания его отменяет; сетка третей при перетаскивании — только в кейсе.
- «Макет / Сетка» — переключатель внизу превью (`setView()`). «Сетка» показывает пост первым в ленте профиля: пользователь вставляет или перетаскивает скриншот профиля Instagram (в этом режиме вставка — скриншот, а не картинка поста), `findGrid()` находит на нём сетку (три равные колонки, плитки 3:4, строки ищутся по совпадению границ с шагом плитки; строка должна быть заполнена хотя бы в двух плитках из трёх; обрезанная снизу строка берётся до нижнего меню телефона), и плитки режутся из скриншота в полном размере. Скриншот живёт только во вкладке, никуда не сохраняется. API Instagram и парсинг не используются: артефакт не может ходить на внешние адреса, а живую ленту нужно видеть без доступов и хранения. Закреплённых постов у Evrone нет, поэтому новый пост всегда первый. Проверялось на синтетических скриншотах (телефон светлый/тёмный, компьютер) из реальных обложек.
- Картинка есть всегда: плейсхолдеры — губы в статье (`assets/sample.webp`) и more.tv в кейсе (`assets/case-sample.jpg`); удалить нельзя, только «Заменить» (перетаскивание и Ctrl/⌘+V работают по всему окну). Логотип в кейсе необязательный, его можно убрать.
- Текст — одно поле `#t1`. В «Сэндвиче» первый Enter делит текст на верх и низ; без Enter слова делятся сами (`textBlocks()`): меньше строк в каждой части, без короткого слова в конце верха, поровну по длине. Слой: в «Сверху»/«Снизу» два варианта (под/над текстом) с иконками из двух квадратов, в «Сэндвиче» ещё «над нижним»/«над верхним» и иконки из трёх квадратов (`syncZ()`).
- Акцентный цвет `#FF5C16` (`--accent`): закраска ползунков и главная кнопка «Скачать» (`.btn.primary`).
- Ползунки: число показывается только у «Ширины букв». Точка на треке — значение по умолчанию (`data-zero`), по рекомендации Figma оранжевая закраска — капсула от этой точки до ручки в любую сторону, точка видна поверх, у сдвинутой ручки цветная сердцевина (`paintRanges()`); у «Масштаба» статьи размер раскладки по умолчанию посередине (±700 px, `resetPos()`), у «Масштаба» кейса и «Размытия маски» точка в начале трека, у «Ширины букв» закраска от начала (`data-origin`), а точка на 60.
- Коррекция цвета (только «Статья»): «Тон красного» (−15…+15°), насыщенность и яркость красных (50–150%) и «Чистота белого и металла» (−100…+100: вправо убирает тёплый налёт, влево добавляет); по умолчанию нейтральные и стоят посередине, чтобы крутить в обе стороны (например, увести слишком жёлтый красный в холодный). Рецепт «нежнее»: +5°, 85%, 122%, 70%. «Размытие маски» 0–10 px (в пикселях картинки 1600 px, масштабируется), по умолчанию 3. Подбиралось в песочнице https://claude.ai/artifact/SdVFkAhSw14NAjPdReBC2t.
- Сохранение: поле имени файла и «Скачать» в «Экспорте» (латиница, транслит, `.png` не редактируется, своё имя у каждого режима). Своего окна нет: на claude.ai после нажатия и так показывается системное подтверждение платформы. Никаких строк статуса; ошибки — в `#warnSave` над полем имени. Предупреждения рядом с источником: про заголовок — `#warnText` под полем текста, про растянутую картинку кейса — значок ⚠ `#warnPic` сразу за подписью «Масштаб», текст во всплывающей подсказке (`.alert`), чтобы ползунок не прыгал; над превью ничего нет.
- Два режима: «Статья» (`state`, `drawArticle()`) и «Кейс» (`caseState`, `drawCase()`); `draw()` выбирает по `mode`. Кейс — только картинка + опциональный логотип клиента, без текста; один пост, без карусели.

- Макеты постов: Figma Evrone-SMM, фрейм «Evrone Instagram» (node 3575:6), файл `RCKCHPqo8R3qLuHxXJqjY04e`.
- Пользователь — маркетолог без Figma: интерфейс и тексты на русском, простые формулировки.
- Промпт иллюстрации: первые три блока на русском (НАРИСУЙ, ЗАДАЧА, ФОРМАТ), STYLE/COLORS/AVOID на английском. Формат — квадрат 1:1, PNG с прозрачным фоном.
- Заголовок: всегда кегль 180, «По умолчанию» = wdth 60, «Настроить» = ползунок «Ширина букв» 25–60. Текст переносится сам по ширине блока, поддерживается неразрывный пробел.
