# Composter

Конструктор постов-статей для Instagram Evrone. Две версии:
- **рабочая** — артефакт https://claude.ai/artifact/VPVrM77jsDNwbu7d2LZzGV, обновляется после каждой правки;
- **стабильная** — GitHub Pages https://den-is-bezrukov.github.io/composter/ (репозиторий https://github.com/den-is-bezrukov/composter, публичный), обновляется только по команде пользователя.

Этот репозиторий — единственный источник правды для обеих версий.

## Как вносить правки

1. Править исходники в `src/`: `page.html` — разметка (слоты `__CSS__` и `__JS__`), `style.css` — стили, `prompt.txt` — промпт иллюстрации, `js/*.js` — скрипт по частям. Части склеиваются в один `<script>` в порядке `JS_ORDER` из `build.py` (`core` → `help` → `theme` → `article` → `color` → `case` → `preview` → `inline` → `files` → `export` → `main`), область видимости общая; код, который выполняется при загрузке и зовёт чужие функции, — только в `main.js`. `core` — `$`, `show`, `onRadio`, `onRange`, `loadImage`, холст и `mode`; `article` — заголовок, раскладки и их контролы; `theme` — кнопка темы; `color` — коррекция цвета; `case` — фон кейса и логотип; `preview` — мышь, колёсико и щипок на превью; `inline` — правка заголовка на превью; `files` — карточки картинок, перетаскивание, вставка; `export` — имя файла и «Скачать»; `main` — `draw()`, `paintRanges()`, `syncResets()`, `setMode()`, раскладка окна и запуск.
2. `python3 build.py` — собирает `index.html` (GitHub Pages) и `dist/artifact.html`.
3. Опубликовать `dist/artifact.html` в артефакт, передав `url` выше, чтобы ссылка не поменялась.
4. Закоммитить изменения (локально, без пуша).

Не править артефакт в обход репозитория. Шрифты в `fonts/` генерируются через `tools/make_fonts.py`, руками их не трогать.

## Стабильная версия

`git push` только когда пользователь явно попросил выкатить стабильную версию (или просто «запушить»); без этого — никогда. Порядок: убедиться, что всё закоммичено и собрано, `git push origin main`, поставить метку следующей версии (`git tag vX.Y`, `git push origin vX.Y`), дождаться сборки Pages и проверить страницу. Откат — пересобрать с нужной метки.

В правом нижнем углу одна круглая кнопка темы (`#themeBtn`, `theme.js`): по кругу «как в системе → светлая → тёмная», ставит `data-theme` на `<html>` (в «как в системе» возвращает `data-theme` хоста, если он был), выбор помнит `localStorage` (`composter-theme`, в `try/catch`). Иконки темы нарисованы в коде, в Figma они перенесены в секцию Icons (Theme Auto / Light / Dark).
- Кейс всегда без пустых краёв: картинка закрывает весь пост (`clampCase()`), масштаб только крупнее, X/Y двигают её в пределах того, насколько она выходит за край (диапазон ползунков пересчитывается в `drawCase()`, если выходить некуда — ползунок выключен). Перетаскивание мышью и масштаб колесом на превью работают. «Вписать целиком», «Без пустых краёв» и фон под краями убраны: такой результат нельзя публиковать.
- Превью в обоих шаблонах: картинку можно тянуть мышью, колёсиком или щипком менять размер вокруг курсора, ползунки едут следом (`panBy()` / `zoomBy()`, пределы — диапазоны ползунков). В «Статье» нажатие на превью сразу показывает оригинал без цветокоррекции, начало перетаскивания его отменяет; сетка третей при перетаскивании — только в кейсе.
- Картинка есть всегда: плейсхолдеры — губы в статье (`assets/sample.webp`) и more.tv в кейсе (`assets/case-sample.jpg`); удалить нельзя, только «Заменить» (перетаскивание и Ctrl/⌘+V работают по всему окну). Логотип в кейсе необязательный, его можно убрать.
- Правка на превью (`inline.js`): двойной клик по строкам заголовка в «Статье» (`textBoxes` из `drawBlock()`, у пустого блока — одна строка) открывает `#inlineText` поверх холста тем же шрифтом и на том же месте (`placeInline()`; высота берётся из строк холста, а не из `scrollHeight`, который на ~11 px больше и поднимал нижний блок), холст этот блок не рисует. Источник правды — `#t1`, предупреждения только под полем слева, на превью ничего. В «Сэндвиче» блок — половина до/после первого Enter; автоделение при входе превращается в настоящий Enter (`fixSandwichSplit()`), Enter в блоке завершает правку. Выход — Esc, клик мимо, смена раскладки/шаблона. Одинарное нажатие и перетаскивание по буквам двигают картинку; над буквами курсор `text`, «оригинал» по нажатию на буквах включается через 250 мс, чтобы двойной клик не мигал.
- Текст — одно поле `#t1`. Неразрывный пробел в поле подсвечен оранжевой дужкой-связкой ‿: под прозрачным `textarea` лежит слой `#t1bg` с тем же текстом (буквы прозрачные, `\u00a0` обёрнут в `.nb`), его рисует `paintNbsp()` из `fitText()` и прокручивает вместе с полем; на превью и в PNG дужки нет. В коде неразрывный пробел писать только как `\u00a0`: буквальный символ теряется при правках. В «Сэндвиче» первый Enter делит текст на верх и низ; без Enter слова делятся сами (`textBlocks()`): меньше строк в каждой части, без короткого слова в конце верха, поровну по длине. Слой: в «Сверху»/«Снизу» два варианта (под/над текстом) с иконками из двух квадратов, в «Сэндвиче» ещё «над нижним»/«над верхним» и иконки из трёх квадратов (`syncZ()`).
- Акцентный цвет `#FF5C16` (`--accent`): закраска ползунков и главная кнопка «Скачать» (`.btn.primary`). Белое поверх него — `--on-accent` (текст «Скачать», иконка активной «?», ручки ползунков); в CSS цвета интерфейса только токенами, `#fff` числом не писать.
- Токены и компоненты в Figma — страница Components, файл больше не тянет библиотеку Figma UI3. Переменные (с 2026-09-29): «Palette» — сырые цвета (`white`, `black`, `gray/100, 200, 600, 700, 800, 900`, `orange/50…950`, `blue/500`, `red/500`) и прозрачности `opacity/90, 50, 30, 10`; `black/N` и `white/N` — не отдельные цвета, а ссылка на `black`/`white` + `opacity/N` (через API такие значения только читаются, менять руками); палитра скрыта из пикеров. `line` (разделители) сейчас равен `line-t` (`black/10` / `white/10`), отдельным токеном оставлен, чтобы их можно было развести; «Composter» (режимы Light/Dark) — смысловые цвета, те же имена, что CSS-токены (`bg`, `bg2`, `canvas`, `seg-on`, `line`, `line-t`, `text-strong`, `text`, `text3`, `inverse`, `focus`, `danger`, `accent`, `accent-hover`, `on-accent`, `warn-bg`, `warn-ink`), значения — ссылки на Palette; «Spacing» — `space-2/4/8/12/16/32`, `radius-sm` 2, `radius` 5, `radius-panel` 13, `radius-pill` 999, к ним привязаны все отступы, промежутки и радиусы компонентов и экранов; «Size» (режимы M/S) — `control-height` 32/24 и `control-pad` 4/0: размер кнопок и полей задаётся режимом на экземпляре или родителе, а не вариантом. У каждой переменной прописан `var(--…)`, и в начале `style.css` те же токены один к одному: палитра (`--black-10` = `color-mix(… var(--black) var(--opacity-10) …)`, как «цвет + прозрачность» в Figma), `--space-*`, `--radius-*`, `--control-*`, затем смысловые цвета ссылками на палитру (светлая тема в `:root`, тёмная в двух блоках ниже). В правилах цвета — только смысловые токены, отступы, промежутки и радиусы из шкалы — только `var(--space-*)` / `var(--radius-*)`; числами остаются значения вне шкалы (15 и 40 px у превью, 56, 19, 3, 4 px), положения (`inset`, `right`…) и цвета самого поста (чёрный холст, текст заголовка, сетка третей). Новый токен заводить сразу в обоих местах. Стили текста Composter/`body`, `body-strong`, `title`, `text`, `text-strong`, `heading` и тени `elev`, `popover` (в CSS это просто числа в правилах, так и оставляем). Секция Tokens — доска цветов в обеих темах; секция UI — минимальный набор компонентов (2026-09-29): `.button` (Style Secondary / Primary / Inverse / Ghost / Floating × State Default/Hover/Disabled/Muted, 11 вариантов, размер — режим Size; Hover повторяет `:hover` из CSS (Secondary/Ghost → `bg2`, Primary → `accent-hover`, Inverse → 90%), на Default висит прототип «While hovering → Hover»; фокус (`focus`) только в CSS; свойства Label, Icon, Show label/icon — кнопка-иконка становится квадратной; Ghost — `text-strong`, как в коде; выбранный сегмент = Secondary, невыбранный = Ghost State=Muted (`text`); у Ghost прозрачная обводка 1 px, как `border:transparent` в CSS, иначе Figma делает выбранную вкладку на 2 px шире), `.seg` и `.field` со слотами (Items / Control), `.input` (с суффиксом `.png`), `.file` (Filled / Empty + Removable), `.toolbelt`, `.sec-h`, `.warn`, `.range`. Варианты в наборе лежат сеткой: по X стиль/тип (`Style`, `Type`, `Zero`), по Y состояние (`State`, `Value`); пустая клетка — сочетания нет; подписей к осям не ставить. Новое сперва собирать из них, а не заводить варианты; слой знака во всех иконках называется `Glyph` — на нём держится цвет при замене иконки. В CSS кнопки так же, как в Figma: один `.btn` (без модификатора — Secondary) + стиль `.primary` / `.inverse` / `.ghost` / `.floating` и `.icon` (только иконка, квадрат); каждый стиль задаёт лишь свои `--btn-bg`, `--btn-bg-hover`, `--btn-line`, `--btn-fg`, новый стиль — одна строка. Размер — не класс: `data-size="s"` на кнопке или любом контейнере (как режим Size в Figma) меняет `--control-height` / `--control-pad` у всего внутри, включая `.seg` и `.fname`. Вкладки `.seg span` остаются отдельным правилом (это радиокнопки), но на тех же токенах. `--text` — приглушённый текст (50%), `--text-strong` — основной (90%). Попап — компонент «Help popover» на странице Screens. Экраны собраны из экземпляров этих компонентов.
- Ползунки: число показывается только у «Ширины букв». Точка на треке — значение по умолчанию (`data-zero`), по рекомендации Figma оранжевая закраска — капсула от этой точки до ручки в любую сторону, точка видна поверх, у сдвинутой ручки цветная сердцевина (`paintRanges()`); у «Масштаба» статьи размер раскладки по умолчанию посередине (±700 px, `resetPos()`), у «Масштаба» кейса и «Размытия маски» точка в начале трека, у «Ширины букв» закраска от начала (`data-origin`), а точка на 60.
- Коррекция цвета (только «Статья»): «Тон красного» (−15…+15°), насыщенность и яркость красных (50–150%) и «Чистота белого и металла» (−100…+100: вправо убирает тёплый налёт, влево добавляет); по умолчанию нейтральные и стоят посередине, чтобы крутить в обе стороны (например, увести слишком жёлтый красный в холодный). Рецепт «нежнее»: +5°, 85%, 122%, 70%. «Размытие маски» 0–10 px (в пикселях картинки 1600 px, масштабируется), по умолчанию 3. Подбиралось в песочнице https://claude.ai/artifact/SdVFkAhSw14NAjPdReBC2t.
- Сохранение: в тулбаре поле имени и «Скачать». Поле облегает текст (`fitName()` меряет его по `#fnameMeasure`, до 192 px, дальше многоточие; пересчёт и после загрузки шрифтов), строчными; `.png` — неизменяемый хвост в той же серой плашке, клик по нему ставит курсор в имя. Имя кейса — по названию фона (пример даёт `primer`), логотип переименовывает только пример (`caseState.sample`), убрали логотип — имя возвращается к фону (`caseState.imgName`). Правила имени (латиница, транслит, `.png` не редактируется, своё имя у каждого режима). Своего окна нет: на claude.ai после нажатия и так показывается системное подтверждение платформы. Никаких строк статуса; ошибки — всплывашка `#warnSave` над тулбаром (прячется через 6 с, при фокусе в имени и при новом нажатии). Предупреждения рядом с источником: про заголовок — `#warnText` под полем текста, про растянутую картинку кейса — значок ⚠ `#warnPic` сразу за подписью «Масштаб», текст во всплывающей подсказке (`.alert`), чтобы ползунок не прыгал; над превью ничего нет.
- Два режима: «Статья» (`state`, `drawArticle()`) и «Кейс» (`caseState`, `drawCase()`); `draw()` выбирает по `mode`. Кейс — только картинка + опциональный логотип клиента, без текста; один пост, без карусели.

- Макеты постов: Figma Evrone-SMM, фрейм «Evrone Instagram» (node 3575:6), файл `RCKCHPqo8R3qLuHxXJqjY04e`.
- Пользователь — маркетолог без Figma: интерфейс и тексты на русском, простые формулировки.
- Промпт иллюстрации: первые три блока на русском (НАРИСУЙ, ЗАДАЧА, ФОРМАТ), STYLE/COLORS/AVOID на английском. Формат — квадрат 1:1, PNG с прозрачным фоном.
- Заголовок: всегда кегль 180, «По умолчанию» = wdth 60, «Настроить» = ползунок «Ширина букв» 25–60. Текст переносится сам по ширине блока, поддерживается неразрывный пробел.
