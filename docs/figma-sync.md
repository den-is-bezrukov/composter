# Связка с Figma

Внешний вид конструктора живёт в Figma, поведение — в коде.

- Figma: [Evrone Post Builder](https://www.figma.com/design/b98SroxNlvHXWPNKJLfUZ6), команда Evrone Inc, file key `b98SroxNlvHXWPNKJLfUZ6`.
- Код: `src/page.html`.

## Что где лежит в Figma

| Страница | Что там | Во что превращается в коде |
|---|---|---|
| Foundations | Коллекция переменных «Builder UI» (Light/Dark), коллекция «Post», текстовые стили | CSS-переменные в `:root`, константы поста в скрипте, `font`-свойства классов |
| Components | Button, Chip, Tab, Layer tab, Drop zone, Slider (Default/Wide), Checkbox, Headline input, File name, Warning, Color input, Step | `.btn`, `.chip`, `.seg span`, `.seg.grid2 span`, `.drop`, `.slider` / `.slider.wide`, `.check`, `textarea`, `.fname`, `.warn`, `input[type=color]`, `.steps li` |
| Screens | 1440×900: «Статья», «Кейс», «Помощь»; узкое окно 1024: вкладки «Текст» и «Картинка» | `.app` (три колонки), `.post-side`, `.workspace`, `.props`, `.savebar`, `.helpview`, медиазапрос ≤1100 px |
| Post templates | «Статья» (Top, Bottom, Sandwich) и «Кейс», 1080×1440 | `LAYOUTS`, поля 30/60, `FS`/`LH`, цвет заголовка, ширина логотипа 540 |

## Соответствия

- Переменная Figma → код: в поле *code syntax* каждой переменной (Dev Mode). Например, `color/accent` → `var(--accent)`, `space/fields` → `var(--space-fields)`, `post/title-size` → `FS`.
- Текстовые стили: у каждого в описании записано, какому CSS он соответствует. `Post/Title`, `UI/Heading`, `UI/Headline Input`, `UI/Step Number` используют Roboto Flex с осями из макетов SMM, wdth 60. В коде это встроенный шрифт `RF60`.
- Компоненты: в описании каждого — класс и правила из кода.

## Синхронизация (делает Claude по слову «синхронизируй»)

1. Прочитать Figma скриптом `tools/figma-read.js` через `use_figma`: переменные по режимам, текстовые стили, геометрию компонентов и шаблонов.
2. Сравнить со снимком `design/figma-baseline.json` (сравнение по смыслу, снимок хранится в сокращённом виде) и посмотреть экраны скриншотом, чтобы заметить новые элементы и перестановки.
3. Показать список изменений: что переносится, что не переносится или требует решения.
4. Перенести в `src/page.html`, `python3 build.py`, опубликовать артефакт, обновить `design/figma-baseline.json`, закоммитить.

Обратное направление: если внешний вид меняется по текстовой просьбе, тем же коммитом обновляется и Figma, чтобы макет не отставал.

## Ограничения

- Точно переносятся: переменные, цвета, размеры, отступы, типографика, раскладка.
- Приблизительно: эффекты (блюр, режимы смешивания). Такие места Claude помечает.
- Ползунок в коде нативный: из Figma в него переносится только цвет акцента.
- Ось `opsz` Figma подбирает сама по кеглю; в коде зафиксирован `opsz 144`, при 180 px результат совпадает.
- Новые элементы на экранах требуют описания поведения: комментарием в Figma рядом с элементом.
